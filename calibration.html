Calibration — the learning loop

After each game, the postmortem-analyst diagnoses what was genuinely different from the

prediction (separating real process error from variance) and appends a dated, specific lesson to

the responsible owner's file here. **Every scout and Carlos reads its own lessons file at the start

of each run and applies them** — that's how the system improves instead of repeating mistakes.

Files (one per owner):

  • scout-form.lessons.md
  • scout-tactics.lessons.md
  • scout-personnel.lessons.md
  • scout-sentiment.lessons.md
  • scout-patterns.lessons.md
  • carlos.lessons.md

Rules: lessons must be specific and testable; pure variance is NOT logged as a lesson; a repeated

miss across games carries more weight than any single game (note repeats).
